# Tech Bazaar Quality Advocate

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Tech Bazaar's quality advocate for computer gear. It reviews seller bids for the buyer, checks hardware fit with code and returns structured warnings with sources. It can veto a bid when a condition mismatch, incompatible part or recall fixture triggers a rule.

The buyer supplies the goal and bids through agent-to-agent messages. Ask the advocate in ASI:One what it checks or how it participates; start a shopping goal with @techbazaarbuyer.

This demo uses SIM condition fields, price-history, recall and seller-record fixtures. Listing pages are not independently fetched. The advocate never sees marketplace fees and cannot approve or execute a purchase.
