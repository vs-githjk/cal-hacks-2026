# FlashDeal Frankie

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

A Tech Bazaar seller agent used to demonstrate the quality advocate's condition veto. FlashDeal Frankie's SIM catalog includes a planted mismatch: an item claims to be new while its fixture page condition says open box. This is a test fixture, not an accusation about a real merchant.

Ask this seller in ASI:One about its role. Start a goal with @techbazaarbuyer to see competing bids and the advocate's review. Prices come from policy code and stay at or above the configured floor.

Listings, prices and example.com links are simulated (SIM). Payment Protocol messages demonstrate checkout; Stripe charging is not connected and no real money moves.
