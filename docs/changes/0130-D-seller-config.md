New contract `contracts/SellerConfig.schema.json` (Lane D, Seller Kit): one seller of record's bidding setup, `{id, name, owner?, archetype, origin SIM|LIVE, port?, shipping?, pricing{mode fixed_margin|discount, margin_pct|discount}, perks[], claims[], listings{sku -> {condition, page_condition?, variant?, price|cost, floor_by_condition{condition -> number}, listing_url, attrs, alt_lines[]}}}`.
Pricing: `fixed_margin` bids cost x (1 + margin_pct/100) and listings carry `cost`; `discount` bids list price x (1 - discount) and listings carry `price`. The floor is per condition and an agent never bids below the floor of the line it offers. `alt_lines` are further condition lines of the same SKU, bid as alternatives in one sealed bid (the Bid contract already says lines are alternatives per SKU); the bid total counts only the cheapest line per SKU.
Changed for Lane A's files: `agents/sellers/sellers.json` entries are now SellerConfigs (the key is the id; old `discount` is `pricing.discount`, old `floor` is `floor_by_condition[condition]`), `seller_4` (Bay Area PC Shop) and `seller_5` (ReNew Refurb) were added, `common.SELLERS` has five entries and `common.SELLER_PORTS` holds the ports (8014, 8015 new). `policy.seller()` returns the same keys as before plus `alt_lines`, `margin_pct`, `origin`; existing sellers' prices and bids are unchanged (pinned in `agents/sellers/test_factory.py`).
Producer: `agents/sellers/factory.py` (`validate_config`, `load_config`, `seller_from_config`, `pick_port`; `ConfigError` is a ValueError with `.errors` = [{field, message}]). Consumers: `seller_agent.py --config`, the Seller Kit API (T2).
