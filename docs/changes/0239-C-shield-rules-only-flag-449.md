# 0239 C Shield says when the classifier is off by mistake (#449 PL-21)
With `SHIELD_CLASSIFIER=1` and no `ANTHROPIC_API_KEY`, Shield ran the rules alone and allowed rule-clean text without a word. Now `shield.classifier.rules_only()` logs one WARNING at first use ("classifier requested but no key: rules only") and `shield.core.screen` adds `"rules_only": true` to the verdict in that case only (the key is absent otherwise, so the v1 key set and the ShieldVerdict contract are unchanged for a normal run). No rule id is added, so an allow does not flip to a quarantine. A caller such as agents/common.screen already passes extra keys through, so a screen can show "rules only".
Affects: shield/classifier.py, shield/core.py, shield/README.md, shield/API.md. No contract file changes.
