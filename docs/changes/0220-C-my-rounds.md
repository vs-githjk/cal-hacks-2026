# 0220 C /buyer shows only the paired buyer's own rounds (#449 PL-3)
New buyer-only market view `my_rounds`: the `round` rows whose need's `buyer_id` is the caller's buyer id (nothing for sellers, the referee or strangers). No table schema change. `/buyer` takes its latest round from it, builds bids, veto and Shield only from that round id, and keeps in the feed only the buyer's own notifications and public floor events whose `ref_id` is one of the buyer's round, bid or mandate ids.
Affects: market/spacetimedb/src/market.ts (`myRoundsView`), index.ts (`my_rounds`), web/src/app/buyer/page.tsx, web/src/lib/screens.ts (`buyerRefIds`, `feedFromRows` takes the id set). Until `spacetime generate` adds `tables.myRounds` to web/src/module_bindings, `/buyer` shows the SIM sample and never another buyer's round.
