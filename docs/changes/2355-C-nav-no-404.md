# 2355 C No 404 from the app's own links (#398, intentionality item 3)
A Playwright pass over every page of the hosted site (all same-origin links, at 390 and 1440) found no link that 404s any more; `/build-board` is no longer linked from main. Two dead ends were left for a stranger: `/seller` on its own was a 404 (the nav opens `/seller/seller-a`), and any wrong address showed the bare framework 404. Now `web/src/app/seller/page.tsx` redirects `/seller` to the seller screen the nav opens, and `web/src/app/not-found.tsx` says there is no page at that address and offers Home, Start as a buyer and Market.
`web/src/lib/routes.test.ts` keeps it that way: every href in the header nav, the buyer nav, the home tiles and the not-found page must match a page under src/app (a [segment] folder matches one segment), and `/build-board` is pinned as missing so the checker itself is tested.
Affects: web/src/app/seller/page.tsx (new), web/src/app/not-found.tsx (new), web/src/lib/routes.test.ts (new). Screenshots in docs/changes/shots/398-nav/.
