# price_position: every price carries its own capture time (PL-26)

`price_position` in `data/scoreboard.json` (open object in `contracts/Scoreboard.schema.json`, no required key added) gains optional keys. `listings[]`, `cheapest_fitting`, `tied_with[]` and `subject` each carry `observed_at`, the time of the capture that showed that price. `as_of` is only when the comparison was assembled, never the time of a price. A listing that a provider had seen before, and that the same store's newest capture by that provider no longer shows, is not counted; it appears in `left_out` with its own `last_seen` and `newest_capture`. `subject` is the priced listing itself with `in_newest_capture` (true, false or null when its URL was never captured). `sentence` says when the priced listing is not in its store's newest capture. Existing keys keep their meaning; `tied_with[]` entries gain `price` and `observed_at`.
