# 0131-D stock holds: two buyers, one unit
- New public table `stock_hold` (id, seller_id, sku_spec, condition, qty, round_id, bid_id, expires_at, state held|sold|released). No buyer id, amount or mandate in it. Written at close for the awarded line (qty = the need quantity, 2 minute expiry), sold by `record_payment`, released by `deny_approval` or by expiry. Available stock = a bid line's stated quantity minus its active holds (held and unexpired, or sold).
- At close, a line with too little stock left gets the per-line reject "sold out to an earlier round" (the same mechanism as "no floor set"), so a bid with another allowed line still ranks on that line and a bid with none shows rank 0 with that reason in `round_result.reasons`. Ranking tie-break is now sealed time, then seller id, then bid id.
- New reducer `deny_approval(mandate_hash, reason)`: the mandate's buyer or the referee, refused after an approval. Releases the held units, writes one `approval_rejected` event, and the reason goes only to the buyer's own notification.
- `create_mandate`, `record_approval` and `record_payment` now move the holds of the deal named by `deal_id` (`<bid id>`, `deal-<bid id>` or `<round id>:<bid id>`): the mandate and approval renew the 2 minutes (or claim a released unit again if it is still free, else refuse with "sold out to an earlier round"), the payment sells. A deal id that names no awarded bid changes nothing.
- New floor event kinds: `stock_held`, `stock_sold`, `stock_released`, `stock_sold_out` (labels carry no amount, buyer or reason). `reset_demo` clears `stock_hold`.
- Does not touch `approval_code`, `loss_report`, `record_loss_report` or `my_loss_reports` (Vedant's PR #71). Bindings regenerated with `spacetime generate` (additive: `stock_hold_table.ts`, `deny_approval_reducer.ts`, index, types). Lane B: `round_result.reasons` already shows the new reason as "ineligible, sold out to an earlier round"; `stock_hold` is subscribable if a screen wants to show the held unit.
- Rules in `docs/ARENA_RULES.md`. Bridge: `python3 demo/bridge.py --two-buyers`.
