# 2340 C Home reads the real market and no longer contradicts itself (#398, intentionality item 2)
Home showed a "NO ROUND YET" pill over a hard-coded "Open for bids, Round 1 of 6" card, asked for a PC "under $2,000" while the build plans with $2,100, and showed five counters at 0/0/0/0/1. Now `web/src/lib/screens.ts homeRound(rounds)` says what the market holds: "no round yet", or the newest round in words ("Motherboard, round 2, open", or "Latest round, closed" for an id that is not a build round), never its raw id. The pill and the card both read it. The question uses `BUILD_CAP_CENTS` (210_000, the same as demo/build.py PLANNER_CAP_CENTS; a test reads build.py and fails if they drift). With no round, the counters are replaced by one line saying none has run yet. The Buyer tile says "The buyer's goal" (M3, app/page.tsx:14).
Affects: web/src/app/page.tsx, web/src/components/arena.tsx (Question: status "none" and an optional detail line), web/src/lib/screens.ts. Screenshots in docs/changes/shots/398-home/.
