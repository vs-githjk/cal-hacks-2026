- Recall Checker: the advocate's recall lookup (`agents/advocate/real_data.py _lookup_brand`) now calls `data.recall_checker.check_product`, the Actor's own matcher. recalled vetoes, unverified is a note. possible is a lead: a GPU name like "rtx 4070 super" has no model code, so the Actor alone cannot tell it from a 4070 Ti; the advocate's existing exact model phrase rule (`data.recalls.recalls_for`, same per-brand cache, no second fetch) then decides veto or caution. So no recall the advocate vetoed before becomes a caution.
- Injection Screen: the Seller Kit (`seller_kit/api.py`) screens every new shop's text (all strings except id and origin, keys included) with the Actor's `screen_text` (Shield rules, classifier off, no network) before anything is written. block or flag: 422 on `listing_text` with the reasons. A screen that raises or did not read the text: 503, fail closed.
- Readiness Report: after a shop is written, the kit runs the Actor's `check_listing` on each listing page (up to 5, in parallel, 8 s budget) and returns `readiness` with the answer; `/sell` shows what an AI shopper sees and the fix per finding. A page not read in time, or that fails, is unreadable and never blocks the shop. A refused shop reads no page.
