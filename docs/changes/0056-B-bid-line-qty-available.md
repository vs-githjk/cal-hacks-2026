B: Bid.lines[] gain qty_available (stock the line offers) and condition; quantity and offered_condition stay as deprecated aliases (Lane A's make_bid sends them; contracts.test.ts proves it still validates). Lines are alternatives per SKU, never a basket. A line is eligible only if qty_available is a finite number above 0 and at least the need quantity, and it is priced at unit_price times the NEED quantity, so extra stock never inflates a bid. The old rule that a line's quantity must equal the need is gone. Affects: Lane A sellers (can offer more stock than asked), Lane D bridge, any Bid reader.
