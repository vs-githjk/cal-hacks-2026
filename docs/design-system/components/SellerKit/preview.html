Seller KitShops made here are SIM
A shop enters its store, pricing, perks and a floor per condition, and gets a seller agent config and the command to start it. The kit cannot verify a real shop, so the label says SIM.
1
Store Name, city, what you sell. Publishes a UCP profile (draft spec, not certified).
2
Pricing and perks List price source, discount step, a perk line per condition.
3
Floors One floor per condition. The referee enforces it: no bid lands below, even from a compromised agent.
4
Start the agent Copy the config and the command. Loss reports arrive after every round you lose.
