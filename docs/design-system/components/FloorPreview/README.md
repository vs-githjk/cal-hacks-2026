The floor as pure SVG and CSS: four sellers in the semantic colours on the ink stage, three sealed rounds, Shield, checker and the deal, in one 24 s loop that plays without a script. The consumer provides the `ArenaScene` rows (`floor-3d.md` maps each row to a phase); the preview uses the reference run. States: sealed, revealed, eaten, blocked, fit uncertain, fit OK, winner, deal. Prev, Pause and Next come from one small script; under reduced motion the end frame shows. Spec in `floor.md`; the three.js version in `floor-3d.md`.
